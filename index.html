Calming Corner Classroom Tools

Talk boards and talking buttons for the classroom. No accounts, nothing to install, and nothing you make is sent anywhere. It all stays in your browser.

Board Maker

Make a tap-to-talk board from a template or a classroom topic, then download it as one file that works offline on the classroom board.

Book Buttons

Make talking picture buttons for an adapted book, using pictures from the book, in a window that floats over the activity.

Teachers checking the topic boards: open the review sheet.
