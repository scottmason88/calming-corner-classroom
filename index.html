Talking Buttons extension

Download Talking Buttons (version 0.9.0, 16 MB)

It isn't in the Chrome Web Store yet, so for now it's installed by hand. This works on a home computer. School computers usually block step 4. There, ask IT to install it for you.

  1. Download the file above and open it. That unzips it into a folder named talking-buttons-0.9.0. Keep that folder somewhere it won't be deleted, such as Documents.
  2. In Chrome, go to chrome://extensions. In Edge, go to edge://extensions.
  3. Turn on Developer mode.
  4. Click Load unpacked and choose the unzipped folder.
  5. Click the puzzle-piece icon in the toolbar and pin Calming Corner Talking Buttons.
  6. Open a Google Slides activity. A small round handle appears in the bottom-right corner. Hold it, or click the toolbar icon, to add buttons.

The extension makes no internet connections and collects nothing. Buttons are saved only in that browser.
